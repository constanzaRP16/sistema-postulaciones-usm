# Sistema de Gestión de Postulaciones USM
Proyecto académico desarrollado para la asignatura Bases de Datos de Ingeniería Civil Informática en la Universidad Técnica Federico Santa María.
El proyecto consiste en una aplicación web para gestionar postulaciones, empresas, sedes, regiones, equipos de trabajo y usuarios con distintos roles de acceso. Posterior a esto, los datos del sistema fueron utilizados para desarrollar dashboards de análisis en Power BI.

## Tecnologías utilizadas
- PHP
- MySQL
- HTML
- CSS
- XAMPP / phpMyAdmin
- Power BI

## Funcionalidades principales
- Inicio de sesión de usuarios.
- Gestión de distintos roles de acceso.
- Creación y edición de postulaciones.
- Consulta y búsqueda de postulaciones.
- Gestión de integrantes de equipos.
- Dashboards diferenciados según el tipo de usuario.
- Visualización y análisis de los datos mediante Power BI.

## Estructura del proyecto
- `web/`: aplicación web desarrollada en PHP.
- `database/`: base de datos MySQL utilizada por el sistema.
- `power-bi/`: dashboard desarrollado en Power BI.
